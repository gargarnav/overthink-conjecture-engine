# Data packet for an AI conjecture proposer

You are given exact data from the PROPOSAL WINDOW only. Propose conjectures that you expect to hold far beyond it (they will be tested on 10x larger data you have not seen). Each proposal needs a natural-language statement, a one-line rationale, and a machine-checkable claim in the language below. Prefer statements the classical miners (listed at the end) cannot express: characterizations of the P-positions, periodicity along any direction, region structure, densities.

## Claim language
Machine-checkable claims about a dataset table, for proposers (e.g. an LLM) that state more
than single-sequence laws.

A claim is a JSON object. Expressions are Python-like and parsed with a strict whitelist
(arithmetic, comparisons, `and`/`or`/`not`, `a if c else b`, `x in (1, 2)`, and the functions
abs, min, max, floor, sqrt), then compiled to vectorized Polars expressions. Nothing is
`eval`-ed. Integer columns are widened to Int64 first, so `y - x` cannot wrap around.

Kinds
-----
predicate     {"kind": "predicate", "table", "group"?, "where"?, "assert"}
              `assert` holds on every row of `table` matching `group` (column == value) and
              `where`.
translation   {"kind": "translation", "table", "group"?, "where"?, "shift": {col: d, ...},
               "value": col, "delta"?: 0}
              For every row r matching group/where whose shifted row r + shift exists:
              value(r + shift) == value(r) + delta. (Periodicity along any direction.)
statistic     {"kind": "statistic", "table", "group"?, "where"?, "expr", "value", "tolerance"}
              The mean of `expr` over the matching rows lies within `tolerance` of `value`.

## Dataset `wsub_subsets5_n1000`

Game: Two heaps (x, y) and a finite subtraction set S. A move removes s tokens from one heap, or s tokens from both heaps, for some s in S. Normal play. This is the finite two-dimensional subtraction game with move vectors (s,0), (0,s), (s,s), s in S.
Proposal window: {'x': 99, 'y': 99}. Tables: `data` (columns ['subtraction_set', 'x', 'y', 'grundy']) and `P` (the rows of `data` with grundy == 0, without grundy).
