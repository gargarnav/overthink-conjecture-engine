# Roadmap (12 months)

Measurable goals by quarter. Progress is tracked with `overthink stats` (`docs/metrics.md`), and results are logged in `docs/results_log.md`. Targets are plans, not results.

| Quarter | Goals | Measured by |
|---|---|---|
| Q1 | First tagged release with Zenodo DOI and Hugging Face mirror. Specialist review of the W({a,a+1}) theorem; arXiv note if confirmed. Second pre-registered LLM-proposer run on a harder 2D family. | release and DOI; review outcome; registry counts per family |
| Q2 | Interval families W({a..b}) and other 2D subtraction rulesets: a 2D finite-window lemma in Lean, so periodic P-sets reduce to finite checks. A statistical proposer (densities, region boundaries) with pre-declared tolerances. | number of statements proved for all parameters |
| Q3 | Second blind rediscovery benchmark on an independent family (ground truth held by a collaborator). Public conjecture benchmark: registry export with proposal/falsification/proof status. | blind score vs pre-registration; benchmark release |
| Q4 | Paper on the system (methods, honest negatives, benchmark). Community contributions (new families, provers). | arXiv preprint; external contributions |

Non-goals: competing with general AI-mathematician systems; closed or commercial components in this repository.
