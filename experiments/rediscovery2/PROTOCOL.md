# Rediscovery run 2 on 4×n Chomp: pre-registered protocol

**Status: binding from the `rediscovery2-frozen` tag on.** Requested by the author on 2026-10-13, after confirming the run-1 scores.

## This run is not blind

The ground truth (`experiments/rediscovery/ground_truth.md`), run 1's output, and the post-hoc analysis in `experiments/rediscovery/REPORT.md` are all known to the person who made these changes. Run 2 measures whether the run-1 lessons improve the pipeline. **Its results can't be presented as independent rediscovery.** In particular, run-1 lesson 1 was written after reading the ground truth.

## Changes from run 1 (and only these)

1. **Functional dependencies are emitted as conjectures** (`src/overthink/conjecture/dependencies.py`). For every column of a table of positions that the data shows is determined by the other columns, the run proposes that dependency. A value column of a table of values (`grundy`) is excluded as definitional. The falsifier checks each dependency on the full table.
2. **Proposal window a ≤ 300** (run 1: a ≤ 100). Falsification at a ≤ 3000, i.e. 10×.
3. **Groups (c, d) ≤ 60** (run 1: ≤ 30), so that second-order statements (across groups) have room to appear.

Everything else (miners, thresholds, selection rules, second-order settings, falsification rule) is unchanged from run 1. Run 1's config reproduces run 1's 73 candidates exactly with the run-2 code (verified before freezing).

**Data:** `chomp4_a3000_c60`, all P-positions with a ≤ 3000 and c ≤ 60, generated by this project's solver. `content_sha256 62e1cbdcc3d4ca68…` (full value in `datasets/chomp4_a3000_c60/manifest.json`). It matches the author's independent n ≤ 3000 data exactly on its range (2,010,792 positions). Grouped views with max_group_value ≤ 60 read only rows with c ≤ 60, so this dataset gives the same views as the full game.

## What will be reported (fixed in advance)

1. The functional-dependency candidates and their status. **Prediction:** d ← (a, b, c) (Unique Extension) and its three siblings will be proposed and survive, because each is a theorem with a one-move proof. Proposing them will therefore count as "found" for v1 C1 / v2 Lemma 1 only in this non-blind sense.
2. Coverage: the number and share of (c, d) groups with c ≤ 60 that get a surviving `a~b` statement, compared with run 1 (61 of 364 sequences got a proposal, 57 survived).
3. Second-order statements: count, statements and status.
4. Totals: survived / refuted / untestable, refutations with counterexamples, and re-proposals (labelled unfalsified).
5. Consistency with run 1: any run-2 survivor that contradicts a run-1 survivor, and any run-1 survivor whose group gets a different statement in run 2.
6. Scores against v1 and v2 using the run-1 rubric, with the non-blind caveat.

No change to code or config between steps 1 and 3. A bug fix means a new tag (`rediscovery2-frozen-v2`) and reporting both runs.
