# Datasets

Each dataset gets its own dataset card here (`<name>.md`) with: description, schema, license, size, content hash, and the exact command that regenerates it. Small samples live in `datasets/samples/`. Full datasets will be hosted on Hugging Face Datasets, with a Zenodo DOI at release.
